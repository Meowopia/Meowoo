# 设备扫码登录

## 目标体验

| 设备 | 登录方式 |
| --- | --- |
| Windows / macOS / Linux | 电脑显示二维码、确认码及有效期；手机扫码登录 OO 并确认后，电脑完成登录。 |
| 平板 | 支持展示二维码让手机确认，并保留可用的系统浏览器登录方案。 |
| TV | 展示二维码及确认码，遥控器可取消、刷新或打开说明。 |
| 手机 | 扫码后打开 OO 的验证页面，核对设备与确认码并明确批准或拒绝；扫码本身不批准登录。 |

PC 的默认含义是“显示登录二维码”，不是强制调用电脑摄像头扫描。所有设备都提供可点击验证链接或手动输入确认码的备用路径。

## 页面与状态

- 登录页：二维码、确认码、剩余有效期、设备说明、取消按钮及备用链接。
- 等待手机确认：依服务端间隔轮询，不重复弹出新二维码。
- 确认成功：校验授权响应并安全保存会话，再显示账号及头像；不能根据扫码动作直接显示登录成功。
- 被拒绝、已过期或已取消：停止轮询，明确提示原因；用户主动选择后再生成新码。
- 网络故障：有限退避重试，不重复创建登录码，不伪装成账号错误。
- 离开登录页面：停止本地轮询，忽略迟到响应；不能在其他页面突然切换账号。

## 账号与安全

- 桌面、平板和 TV 按各自获准的客户端合同接入；未注册的桌面客户端不能借用 TV 身份。
- 二维码只编码服务端提供的验证链接，不包含访问令牌、刷新令牌或设备授权凭据。
- 手机确认页应显示应用/设备、请求权限及可核对的用户码；确认授权不应由客户端代替用户完成。
- 令牌使用平台安全存储，不出现在日志、二维码、剪贴板或公开链接中。
- 账号切换、退出、过期和撤销必须隔离或清除相关会话，不能混用不同账号的云存档。

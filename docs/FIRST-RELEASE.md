# Meowoo 0.1.0 首版范围

**状态：开发中，尚未发布。** 本页说明首版目标，不代表已经完成设备验收。

Meowoo（喵呜）是一款跨平台个人媒体客户端，以内容浏览、观看和阅读为主，扩展及媒体服务器作为内容接入方式。首批交付聚焦 Android 手机（ARM64，Android 9 或更高版本）；其他平台继续保留在产品路线内，不将开发目标标记为已交付。

## 首版目标

- Android 手机的内容浏览、详情、选集、视频播放、漫画及小说阅读。
- 本地历史、收藏及继续观看／阅读；网络或服务故障不伪装为空记录。
- 默认公开演示源、自定义扩展管理及基础 Jellyfin 接入。默认演示内容不等同于完整商业影视片库。
- “我的”、设置及基础皮肤；保留来源和失败原因，不展示虚构账号或同步状态。
- 内容入口默认隔离，退出或关闭后不继续沿用失效会话。
- 平板和 TV 后续独立验收。TV 需要独立验证焦点、返回键、遥控器与触屏；验证前不标记正式支持。

## 发布前必须通过

- 冷启动、重复进入退出、切集、换线路、进度恢复、后台返回和断网重试。
- 漫画／小说切章，跨来源及同源不同作品不能误用缓存。
- 历史首次加载、读取失败、重试、删除及重启后的恢复。
- 窄屏、横屏、明暗模式、大字体及实际设备操作。
- 使用正式包身份和明确的发布签名；不得静默用调试签名替代正式签名。
- 保留上游许可证与必要声明，未完成能力不标记可用。

## 后续版本

完整动态装扮、独立头像框、OO 登录与跨设备云同步、自动字幕翻译、更多媒体服务器与平台适配按验收进度交付。当前更新通道尚未开放，不接收 Miru 上游安装包作为 Meowoo 更新。
